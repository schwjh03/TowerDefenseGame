# Erdspire Defense — The Roads Home

A browser tower-defense story in three chapters: Ashen Road, Drowned Archive and Glasswood Ridge. Meet Edda, Iven and Sera, choose an escort or scouting approach, defend eight waves on each distinct map, and face its named guardian. Completed chapters unlock the next road and award relics once. Campaign unlocks, route choices and shrine upgrades stay in browser storage; unfinished battles restart.

Run a static server in this folder and open index.html. No installation, account or backend is needed. A desktop or landscape view is recommended. Drag a tower from the panel onto open ground, select it to upgrade, then start each wave. Camp returns safely to chapter selection. There are two tower families with three upgrade paths each.

Run `node --test tests/campaign.test.mjs` for chapter unlocking, both route choices, rewards, migrations and wave generation. Browser assets include the existing prototype art. This is an original prototype and its balance is still being tuned.
